# qnxg agent

> 注：目前的代码是为了看效果而用 ai 快速跑出来的，可能各方面看上去都有点简陋。

因为运行的是 pi sdk，所以会加载电脑上的 pi agent 的模型配置。

pi的配置文件主要有两个 auth.json 和 model.json，其中 auth.json 会重定向到项目内，而 model.json 目前还是加载本地的 model.json。

## 运行

```
npx tsx agent.tsx
```

## feature

提问样例：查询一下电费查询接口的情况
